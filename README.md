## How it works

The repository contains three main files:

- `README.md`: explains the internship context, the purpose of the repository and the confidentiality approach.
- `campaigns.csv`: contains fictional and anonymised campaign data used for demonstration.
- `dashboard.py`: reads the CSV file and calculates simple campaign indicators such as campaign status, platform distribution, views, likes and comments.

The script was kept intentionally simple and clear so that the logic can be easily understood and reviewed.

## How to use

1. Keep `dashboard.py` and `campaigns.csv` in the same folder.
2. Run `dashboard.py` with Python.
3. The script reads the campaign data from the CSV file.
4. It displays a simple summary of campaign activity and performance indicators.

The repository is designed as a technical demonstration only. It does not contain any confidential or real company data.
